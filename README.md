## Testing data and participants

`testing-data/` holds results from sessions run on classmates. Anything identifying belongs in `raw-private/` subfolders, which are gitignored. Commit the anonymised/aggregated version.

## AI use

The Design Concept and Evaluation reports are **open assessment** — AI tools are permitted. The Interactive Prototypes are **secure assessment**: all AI use must be declared using the UQ Library acknowledgement table format, and IP1 additionally requires a Statement of Originality committed to this repo.

`AI_Acknowledgment_Coversheet_Template.docx` in the root is the UQ template.
