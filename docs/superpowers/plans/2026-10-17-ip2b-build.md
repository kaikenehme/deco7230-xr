# IP2b Build Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the IP2a Unity prototype into IP2b: two warm, dressed rooms (contemporary living, mid-century bedroom), pull-from-anything, a fan-deck palette, floor tint, closable curtains, toss-to-commit, and an MR passthrough showcase — test-ready by Wed 21 Oct freeze.

**Architecture:** Same project, moved to `ip2b/`. Scene stays generated by `SceneBuilder.cs`; rooms stay `RoomPreset` assets authored by `PresetAuthoring.cs`. New furniture comes from Sketchfab via Blender (decimated, exported FBX) into `Assets/Catalogue/Local/`, baked to prefabs by `CatalogueImporter`. New behaviours are small MonoBehaviours with pure static cores so EditMode tests cover the logic.

**Tech Stack:** Unity 6000.0.80f1 · URP 17.0.4 · XRI 3.1.2 · OpenXR 1.14.3 · (T9) AR Foundation 6.0.x + Unity OpenXR: Meta 2.0.x · Blender 5.2 via Blender MCP · NUnit EditMode/PlayMode.

**Spec:** `docs/superpowers/specs/2026-10-17-ip2b-design.md` (read it first).

## Global Constraints

- Edit `SceneBuilder.cs` / `PresetAuthoring.cs`, **never** `Room.unity` or preset `.asset` files by hand.
- No headset until Fri 23 Oct. Verify in editor: EditMode + PlayMode tests, `SnapshotTests` renders, desktop-mode lap. **Never build an APK without Kaike's explicit go.**
- VR is the default mode. Nothing in the VR path may depend on AR Foundation / MR code (T9 must be removable by deleting its files + packages).
- Quest budget: ≤ 30 000 triangles per furniture prefab; ≤ 250 000 triangles per dressed room; textures ≤ 2048 px.
- Assets: Sketchfab CC-BY / Free Standard only (never NoDerivs), Poly Haven CC0. Every new asset gets a line in `Assets/Catalogue/CREDITS.md` (title, author, licence, URL).
- **No menus added.** New controls are touchable/grabbable objects in the room (`ITouchable` for touch).
- Brightness never snaps: any daylight change from curtains fades over `CurtainController.FadeSeconds = 1.0f`.
- Furniture is **pull-only** (gives colour, never takes paint). Walls and floor take paint.
- Cut order if Wed 21 is at risk: **T10 toss first**.
- Before any Refresh/compile in a live editor: check `isPlaying`, `editor_stop`. No batchmode while the GUI editor has the project open.

## Review Focus

1. **Pulling while already holding a sample** (second pull with the same hand, or pull with the other hand mid-fan) — expect: previous sample is replaced, never two fans in one hand. → test in T5.
2. **Hold-up and toss overlapping** — release within `PreviewRadius` of a wall while moving fast must commit by hold-up exactly once, never twice. → test in T10.
3. **Curtains toggled mid-fade, and time-of-day changed while curtains closed** — fade reverses smoothly from the current value; clock change while closed keeps the room dark. → test in T8.
4. **Switching preset while a curtain is closed / a fan is open / MR is on** — room reloads cleanly: curtains open, fan gone, MR off. → test in T3 (preset) and T9 (MR).
5. **Furniture moved against a wall or out of the smaller room** — stays inside floor bounds with `FurnitureSlot.FloorMargin`. → test in T7.
