## Constraints found in the code that shape the design

- `Surface` binds **one** renderer (`Surface.cs:39-50`); `HoldUpPreviewer` uses one collider (`:51-53`); `MarkTool`/`SamplePuller` use `GetComponent<Surface>()` on the collider GO. A four-cube window wall needs multi-renderer/collider support (T2).
- `Sample.Init` takes `source.DisplayColor` = the material's tint. A **textured** kept floor/sofa has tint white, so the pulled palette would be grey. Needs an authored sample colour (T2, T8, T11).
- `Surface.Restore/Preview/Commit` refuse `Keep`; presets need a `SetBaseLook` that bypasses the guard.
- URP asset: main-light shadows on at 2048, `m_ShadowDistance: 50`, `m_SoftShadowsSupported: 0`.
- XRI Starter rig already has thumbstick manipulation on for far-held objects (`Left_NearFarInteractor.prefab`: `m_UseManipulationInput: 1`, X = yaw, Y = pitch, far attach floats along the ray). `ControllerInputActionManager` disables locomotion during **Far** select only; snap turn stays live during a **Near** grab.
- Classic XR Device Simulator binds keys `1/2/3` (axis targets), `T/Y`, `Tab`, `\`. Facilitator keys must be **F1–F3** (presets) and **F5–F10** (time stops).
- Poly Haven `lighting` has no floor lamps; `desk_lamp_arm_01` is skinned (importer only bakes `MeshFilter`s). Lighting category = 1 piece (`vintage_oil_lamp`). `wall_clock` exists (jpg diffuse; normal/rough are exr and get skipped — fine, hands are overlaid anyway).
- Left `primaryButton` (X) is unbound; free for the facilitator "sample in hand" hold.
- No tool config hardcodes the project path (`~/.claude.json` clean). Plans/docs under `ip1/` and `docs/superpowers/plans/` reference the old path historically; leave them.

## Design notes

1. **Window wall** = one logical `Surface` (root + 4 cube children) so paint, menu, schemes and hold-up preview treat it as one wall. Fallback if T2 slips: four independent `MakeSurface` pieces with a `Surface.Linked` list propagating Preview/Commit/Revert.
2. **Lighting ownership**: two writers, disjoint resources. Night ambient floor ~0.06–0.10 keeps the room navigable with the lamp Off. Defaults: 10:00 + lamp Warm.
3. **Presets vs slots vs schemes**: `FurnitureSlot.Origin` decides what `Apply` clears. Surfaces found by **name** (`Surface.All` order is OnEnable order), always `s != null`. `SetBaseLook` redefines the shipped baseline so `Revert` returns to the preset look. `ControllerMenu.LateUpdate` (`:129`) already hides on a destroyed `Current`.
4. **Entry affordance** is a separate `PullAffordance` component, not inside `Surface` (`Surface` "never knows samples or menus exist", `Surface.cs:8`). Peel = XRI `attachEaseInTime`, no animation code.
5. **Placement + rotation**: keep the Starter rig; disable `trackPosition/trackRotation` on furniture; drive pose from `FurnitureSlot.Update` by `NearFarInteractor.selectionRegion`; own `primary2DAxis` action for yaw; `LocomotionLock` covers Near grabs (Far already suppressed by `ControllerInputActionManager`).
6. **Facilitator keys** (editor only): F1–F3 presets, F5–F10 time. X-hold on the left controller for sample-in-hand works on device too.
7. Hemisphere realism of the sun path is not modelled; one line in the testing plan says so.
