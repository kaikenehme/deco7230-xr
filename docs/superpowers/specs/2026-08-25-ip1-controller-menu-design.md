```

  Catalogue.asset                         ScriptableObject — the single source the menu reads
  Furniture/<id>/<id>.gltf + textures     glTFast-imported; one Prefab per model in Prefabs/
  Materials/<id>/*.jpg + <id>.mat         URP/Lit, albedo + normal, tiling per category
  Paints/dulux.json                       {name, hex}[]

Assets/Scripts/Runtime/
  Catalogue.cs        SO: List<PaintOption> paints; List<MaterialOption> materials; List<FurnitureOption> furniture
                      PaintOption {string name; Color color}
                      MaterialOption {string name; Material material; SurfaceKind targets /*flags*/; Vector2 tiling}
                      FurnitureOption {string name; GameObject prefab; FurnitureCategory category}
  SurfaceKind.cs      [Flags] enum { Floor=1, Wall=2, Ceiling=4, Trim=8 }   — set on Surface (new field `kind`)
  Surface.cs (+)      Material CommittedMaterial; PreviewMaterial(Material) / RevertMaterial() / CommitMaterial(Material)
                      Same Keep guard as colour. Apply = renderer.material = Instantiate(m) with current colour tint.
  SchemeManager (+)   snapshot value becomes struct SurfaceLook {Color color; Material material}
  FurnitureSlot.cs    on every furniture root. Swap(FurnitureOption): instantiate prefab at slot pose, destroy old visual,
                      keep slot GO. Remove(): destroy visual, slot stays (so scheme/undo trivial). Static Spawn(option, pos).
                      Requires XRGrabInteractable (kinematic, track pos+rot), rotation locked to Y via
                      RotationAxisLockGrabTransformer (from XRI Starter Assets, already in project). On release: y = 0.
  MenuTarget.cs       on every Surface and FurnitureSlot. Exposes Tabs (Paint|Material|Furniture|Swap|Remove) computed
                      from Surface.kind / slot; IXRSelectInteractable via XRSimpleInteractable so the Near-Far ray selects it.
  ControllerMenu.cs   single instance, canvas child of Left Controller. Show(MenuTarget) builds tabs + button grid from
                      Catalogue. Button hover → target.Surface.Preview(color) / PreviewMaterial(m); exit → Revert; click →
                      Commit. Furniture buttons → slot.Swap / FurnitureSlot.Spawn at last ray hit on Floor. Hide() reverts
                      any live preview. Canvas billboards to Main Camera each frame.
  MenuSelectRelay.cs  on Right Controller: listens to Near-Far Interactor selectEntered → if MenuTarget, ControllerMenu.Show.
                      Records last floor hit point for spawn.

Assets/Editor/
  CatalogueImporter.cs  MenuItem "Renovation/Import Catalogue": downloads (UnityWebRequest, Editor), unzips ambientCG,

  SceneBuilder.cs (+)   adds SurfaceKind per surface, MenuTarget on all surfaces/slots, FurnitureSlot on Sofa/SideTable,
```

## 5. Interaction flow

1. Right controller ray (existing Near-Far Interactor + LineVisual) over a surface or furniture; trigger selects.
2. Menu appears on left controller (≈ 0.28 m wide canvas, faces head). Tabs filtered by target:
   - Floor → Paint · Material(floor) · Furniture(add)
   - Wall / Ceiling / Trim / Door → Paint · Material(wall)
   - Furniture → Swap · Remove
   - Any **Keep** surface → single button "This is staying — change it?" → `ToggleState()` then re-show.
3. Hover a swatch → live preview on target (colour or material). Move off → revert. Click → commit.
4. Furniture: Swap replaces in place (same pose). Add spawns on floor at last hit point, 0.5 m toward player.
   Grab with either hand to move; wrist twist rotates (Y-locked). Release → snap to floor.
5. Menu closes: trigger on empty space, or left-controller secondary press. Close always reverts live preview.
6. Existing loop untouched: sample pull/hold/tune/commit continue to work; both methods write the same
   `Surface` state; schemes capture both.

## 6. Edge cases

| Case | Behaviour |
|---|---|
| Preview live when menu hidden/target destroyed | `Hide()` reverts; `MenuTarget.OnDisable` reverts |
| Material on a surface then colour commit | colour tints material (URP BaseColor); tile default tint = white |
| Scheme restore | restores material then colour, per surface; slots not in schemes (v2 scope) |
| Furniture spawned outside room | clamp XZ to floor bounds − 0.3 m |
| Two rays select at once | last select wins; one menu instance |
| Missing Catalogue asset | menu logs error and shows nothing; app keeps running |
| glTF import fails for one model | importer logs, skips, continues; Catalogue lists what succeeded |
